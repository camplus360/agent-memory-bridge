# Code of Conduct

Be respectful, constructive, and considerate when participating in this project
— in issues, pull requests, and discussions.

- Use welcoming and inclusive language.
- Focus on what is best for the project and the community.
- Accept constructive criticism gracefully.
- Do not harass, insult, or troll others; no discrimination of any kind.

Unacceptable behavior may result in removal of comments, issues, or contributions.

Report concerns to the maintainer at **camplus360@163.com**. Reports will be
reviewed and kept confidential.

This is a short, pragmatic code of conduct; the spirit of the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
applies.
